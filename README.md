# MarkdownObserver personal build

Builds [MarkdownObserver](https://github.com/larspohlmann/markdownobserver) 1.4.1 for Apple Silicon using GitHub Actions. The upstream source is pinned to commit `0ce6b934be1c6146a87a86d197c00bb26bb71be3`.

Run **Build MarkdownObserver** from the Actions tab. Download the `MarkdownObserver-Apple-Silicon` artifact from a successful run, extract `MarkdownObserver.zip`, and move the app to Applications.

This is an unofficial personal build. It uses ad-hoc signing for local use and is not notarized by Apple. The original application is MIT licensed; see the upstream repository for its source and third-party notices.

No Apple account or local Xcode installation is needed to build through this workflow.
